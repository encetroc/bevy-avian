# 06: Add basic dynamic test objects

**What to build:** Add cubes, spheres, crates, and barrels as dynamic bodies that respond to gravity, contacts, and player pushes.

**Blocked by:** 02, 05

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Each object falls and collides correctly.
- [ ] The player can push lightweight objects without becoming unstable.

## Tests

- [ ] Drop each object onto the floor.
- [ ] Walk into each object and verify it responds physically.
