# 22: Build the density and mass laboratory

**What to build:** Create identical-looking light, medium, and heavy objects using different density or mass settings.

**Blocked by:** 14, 19

**Status:** ready-for-agent

## Acceptance criteria

- [ ] The objects appear visually equivalent.
- [ ] Their push and grab responses are noticeably different.

## Tests

- [ ] Push each object with the player.
- [ ] Grab and drag each object and compare lag.
