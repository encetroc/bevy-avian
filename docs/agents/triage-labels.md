# Triage labels

This repository uses the default triage label vocabulary. Each canonical triage role maps to a label with the same name.

| Canonical role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

Use these labels consistently when triaging local Markdown issues under `.scratch/<feature>/`.
